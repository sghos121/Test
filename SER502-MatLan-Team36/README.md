# SER502-MatLan-Team36

Description :- The purpose of MatLan is designed for matrix operations, particularly those relevant to heavy computations. It is widely used and required as of today. The focus will be on making a robust interface for matrix operations.

System Support and Development Tools :-
1.  System Support (Operating Systems): The MatLan compiler and runtime environment are designed to be cross-platform, with primary support for:
Linux: Development and testing are conducted on Linux. The use of standard tools like Flex, Bison, and g++ ensures compatibility with most Linux distributions.
macOS: macOS is also a target platform, as the tools used are available on macOS. The compilation process should be similar to Linux.
Windows: Windows support is provided through MinGW or WSL (Windows Subsystem for Linux). These environments allow the use of Flex, Bison, and g++ on Windows.

2.  Development Tools:

   
Lexical Analysis: Flex, a fast lexical analyzer generator. Flex is used to create the lexer for MatLan. It's a command-line tool that generates C++ code for the lexer based on regular expression patterns.


Parsing: Bison, a parser generator. Bison is used to create the parser for MatLan. It takes a context-free grammar definition and generates C++ code for the parser. Bison works closely with Flex.


Compilation/Runtime: g++ is the primary compiler for the project. It's used to compile the lexer and parser code (generated by Flex and Bison) and any other C++ code for the runtime environment. g++ is chosen for its wide availability and standards compliance.


Build System: Make, a build automation tool. Make is used to automate the compilation and linking process. A Makefile is provided to simplify building the MatLan compiler and runtime.
Version Control: Git is used for version control. The project is hosted on GitHub, and Git is essential for collaboration and tracking changes.

3.   Tool Choices: All tools (Flex, Bison, g++, Make, Git) are open-source and freely available, satisfying the project requirements. These tools are widely used in compiler construction and provide a robust and well-established development environment. They are command-line tools, which aligns with the requirements.

Running it on your system - 
1. Inside the src folder you will see mutiple files along with the lexer.l, parser.y, Makefile (for building C-based files), these files are generated by running the '''make''' command inside the src folder.
2. So, to run the code files of the new language run - ./matrixlang testfile_name
